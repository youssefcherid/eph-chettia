# موقع EPH Chettia — نسخة GitHub Pages

## النشر
1. فك ضغط الأرشيف.
2. ارفع كل الملفات والمجلدات الموجودة داخله إلى جذر المستودع `eph-chettia` على GitHub.
3. تأكد أن `index.html` في الجذر.
4. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.

## الصور والشعار
تم تضمين الشعار داخل `index.html` لتفادي مشكلة عدم رفع مجلد الصور، وأضيفت رسومات SVG محلية للمستشفى وبطاقات الخدمات. تبقى نسخة الشعار الأصلية داخل `assets/`.

هذه نسخة ثابتة لـ GitHub Pages؛ لا تشغّل PHP أو MySQL. الرسمة التوضيحية للمستشفى ليست صورة حقيقية لمبنى المؤسسة.
