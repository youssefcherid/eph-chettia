# EPH Chettia — GitHub Pages

نسخة ثابتة جاهزة للنشر على GitHub Pages.

## النشر
1. أنشئ مستودعًا عامًا باسم `eph-chettia` في حساب GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع مجلدًا إضافيًا يحتوي الملفات).
3. افتح Settings → Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر Branch: `main` والمجلد `/(root)` ثم Save.
6. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

## حدود هذه النسخة
هذه نسخة HTML/CSS/JavaScript ثابتة. لا تشغّل PHP أو MySQL ولا تحتوي على لوحة إدارة ديناميكية. الأخبار والوثائق والدروس تحتاج إلى تعديل الملفات وإعادة رفعها، أو ربط خدمات خارجية. لا تضع أي بيانات مرضى أو معلومات سرية في مستودع عام.
